## 欢迎来到我的博客！

这是我使用 **Hugo** 静态网站生成器创建的第一篇博客文章。Hugo 是一个用 Go 语言编写的静态网站生成器，以其构建速度快而闻名。

## 为什么选择Hugo？

### 🚀 速度快
Hugo 是世界上最快的静态网站生成器之一，可以在几毫秒内构建大型网站。

### 📝 Markdown支持
完全支持Markdown语法，让写作变得简单而高效。

### 🎨 主题丰富
有大量精美的主题可供选择，我选择了简洁的 PaperMod 主题。

### 🔧 易于配置
通过简单的配置文件就能实现强大的功能。

## Hugo + GitHub Pages 的优势

1. **免费托管**：GitHub Pages 提供免费的静态网站托管
2. **自动部署**：通过 GitHub Actions 实现自动化部署
3. **版本控制**：利用 Git 进行内容版本管理
4. **自定义域名**：支持绑定自己的域名

## 代码高亮示例

Hugo 内置支持语法高亮，例如：

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, Hugo!")
}
```

```javascript
// JavaScript 示例
function greet(name) {
    return `Hello, ${name}!`;
}

console.log(greet("Hugo"));
```

## 总结

使用 Hugo + GitHub Pages 搭建博客是一个很好的选择，特别适合：

- 程序员和技术爱好者
- 喜欢用 Markdown 写作的人
- 需要版本控制的内容创作者
- 希望网站加载速度快的用户
